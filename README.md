# היסטולוגיה – הכנה למבחן

מאגר שאלות אינטראקטיבי להכנה למבחן בהיסטולוגיה (אוניברסיטת רייכמן, מחזור ג׳):

- **מבחן מועד א׳ (27.11)** – 41 שאלות עם התשובות הנכונות מהמשוב
- **שחזור מבחן רייכמן** – 50 שאלות מצילומי המסך
- **סימולציה** – 85 שאלות עם הסברים ואימות בספר הקורס
- **בחני בוקר** – 4 בחני Moodle + 3 בחנים מצילומי WhatsApp
- **שאלות נוספות** – 77 שאלות שנכתבו לפי רשימות המושגים
- **Kahoot בכיתה** – 30 שאלות מצילומי תרגול הקאהוט, עם התמונות
- **חשוב למבחן** – 32 שאלות לפי המסמך "בהרצאה אמרו שזה חשוב למבחן" + תמלול המסמך בלשונית נפרדת
- **מעבדות** – 41 מטלות מארבע חוברות המעבדה (כבד ולבלב, כלי דם, נשימה, עיכול) עם תשובות מוצעות ועמודי החוברת, וכן כל מטלה כשאלה אמריקאית בתרגול (מקור "מטלות מעבדה")

לכל שאלה: ציון המקור (קובץ), נושא, תמונת H&E כשיש, הסבר. סינון לפי מקור/נושא, חיפוש, "רק עם תמונה", ובוחן אקראי של 50 שאלות עם ציון.

`index.html` + תיקיית `img/`, ללא תלויות, עובד גם אופליין.

ההסברים והשאלות הנוספות נכתבו לצורכי לימוד ואינם תחליף לחומר הקורס.
